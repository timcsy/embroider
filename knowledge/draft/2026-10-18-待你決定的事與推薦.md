# 待你決定的事與推薦

怎麼冒出來的：2026-10-18 使用者要我用 knowie 持續迭代，能決定的照推薦做，不能自己決定的記在這裡並附推薦，不阻塞其他工作。

## 需要你決定（我不替你做）

1. **授權**。目前各 crate 標 `MIT OR Apache-2.0`，根目錄沒有授權檔。
   推薦：維持 `MIT OR Apache-2.0`（Rust 慣例、對個人使用者與他人二次開發都最寬鬆），並補兩個 LICENSE 檔。字型已各自是 OFL，不受影響。
   不做的原因：授權是作者對外的法律聲明。
2. **專案名稱**。資料夾 `embroider`，介面標題「刺繡小幫手」。
   推薦：對外（開源 repo）用 `embroider`，給媽媽看的介面維持「刺繡小幫手」，兩者不衝突。
3. **第一次 git commit 與是否推到公開網站**。我已 `git init`（本機、可還原），沒有 commit。
   推薦：由你確認內容後做第一次 commit。需要 commit 時跟我說，我會照 `.gitignore` 排除 `target/`、`out/`、`node_modules/`。
4. **放到哪個 HTTPS 網址**，才能在媽媽手機「加到主畫面」與離線（區域網路 http 位址做不到）。
   推薦：靜態託管（GitHub Pages 或 Cloudflare Pages，免費、純靜態，與「資料不離開手機」一致）。
   不做的原因：要用你的帳號與公開內容。我可以先把 `web/dist` 的部署設定（含 base path 檢查）備好。
