# 願景

## 問題陳述

媽媽是刺繡與拼布高手，手邊只有 Android 手機。現有刺繡軟體貴、為電腦設計、操作複雜，她用不順手。

## 核心想法

在手機瀏覽器輸入文字（中英文）或選簡單圖片，看到接近真實的刺繡預覽，選繡框，把檔案存到 USB 隨身碟，交給 bernette B70 繡出來。

## 現狀

可交給媽媽試用的版本已完成；做了什麼與每項需求由什麼測試保證，見 [traceability](../specs/001-embroidery-text-tool/traceability.md)。圖片轉換已依形狀選針法並依重要性簡化（[002](history/002-針法從只用填充到依形狀選擇.md)、[003](history/003-圖片從忠實描圖到依重要性簡化.md)）。下一步卡在實機：B70 讀得到哪種格式、檔名規則、各項門檻、USB 流程、媽媽能否自己完成。

## 架構

Rust 核心（針跡生成、格式編碼、驗證）編成 WASM，由行動優先的 PWA（Svelte 5）透過 Web Worker 呼叫；資料全程只在手機上處理。
輸出格式走註冊表，格式不猜、全部輸出讓實機決定（見 [格式不猜-全部輸出](history/格式不猜-全部輸出.md)）。所有門檻數值是假設值，集中在 `Settings`，待實測校正。

## 路線圖

### 階段 1 收尾：媽媽實機驗收

交付物已完成（決策與理由：[格式不猜-全部輸出](history/格式不猜-全部輸出.md)），剩下只有實機能回答的事。

**成功標準：**
- [ ] 媽媽自己完成一次從輸入文字到繡出成品，不需要旁人協助
- [ ] 確認 B70 能讀取的檔案格式（步驟見 [quickstart 第五節](../specs/001-embroidery-text-tool/quickstart.md)）
- [ ] 依成品校正門檻數值（`Settings`）
- [ ] 圖片：用一張簡單的圖（如花）與一張有凹凸形狀的圖試繡，緞面、混色、輪廓填充、方向場填充不斷針、不過厚，成品認得出、順眼（概念：[簡化到看起來舒服，比忠實更重要](concepts/簡化到看起來舒服比忠實更重要.md)）

### 階段 2：編輯器（媽媽想到什麼就做得出來）

設計準則、版面與完整驗收見 [編輯器路線圖](draft/2026-10-19-編輯器路線圖.md)（進行中的設計依據，完成後轉入 history）。根公理不變：媽媽是第一位使用者，手繪等功能不能讓她的主畫面變複雜。

- [ ] E1 編輯器骨架：程式完成，待實機與媽媽試用（多物件（文字、圖片、簡單形狀）、拖移縮放旋轉、復原重做、複製、上下層、對齊；手機、平板、電腦版面）
- [ ] E2 手繪：程式完成，待媽媽試用（畫線自動走平針或緞面，封閉圖形可填滿）
- [ ] E3 拼布常用：程式完成，待媽媽試用（整排重複、鏡像、弧形文字、邊框）
