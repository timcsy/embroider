# 願景

## 問題陳述

媽媽是刺繡與拼布高手，手邊只有 Android 手機。現有刺繡軟體貴、為電腦設計、操作複雜，她用不順手。

## 核心想法

在手機瀏覽器輸入文字（中英文）或選簡單圖片，看到接近真實的刺繡預覽，選繡框，把檔案存到 USB 隨身碟，交給 bernette B70 繡出來。

## 現狀

可交給媽媽試用的版本已完成；做了什麼與每項需求由什麼測試保證，見 [traceability](../specs/001-embroidery-text-tool/traceability.md)。下一步卡在實機：B70 讀得到哪種格式、檔名規則、各項門檻、USB 流程、媽媽能否自己完成。

## 架構

Rust 核心（針跡生成、格式編碼、驗證）編成 WASM，由行動優先的 PWA（Svelte 5）透過 Web Worker 呼叫；資料全程只在手機上處理。
輸出格式走註冊表，格式不猜、全部輸出讓實機決定（見 [格式不猜-全部輸出](history/格式不猜-全部輸出.md)）。所有門檻數值是假設值，集中在 `Settings`，待實測校正。

## 路線圖

### 階段 1 收尾：媽媽實機驗收

交付物已完成（決策與理由：[格式不猜-全部輸出](history/格式不猜-全部輸出.md)），剩下只有實機能回答的事。

**成功標準：**
- [ ] 媽媽自己完成一次從輸入文字到繡出成品，不需要旁人協助
- [ ] 確認 B70 能讀取的檔案格式（步驟見 [quickstart 第五節](../specs/001-embroidery-text-tool/quickstart.md)）
- [ ] 依成品校正門檻數值（`Settings`）
