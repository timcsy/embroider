# 驗證指南（Quickstart）

目的：在沒有 B70 實機的情況下，證明功能端到端可運作；並整理最後交給媽媽測試的清單。

## 前置條件

- Rust stable（1.94 以上）、`wasm-pack`、`wasm32-unknown-unknown` 目標
- Node.js 24、npm
- `uv`（用來執行 Python 的 pyembroidery 交叉驗證）

## 一、核心測試（不需要瀏覽器）

```bash
cargo test --workspace
```

預期：全部通過，包含 golden、往返、屬性測試。

## 二、輸出檔交叉驗證

```bash
cargo run -p stitch-cli -- sample --text "Amy 2026" --hoop b70-medium --out ./out
uv run --no-project --with pyembroidery python -I tools/verify_outputs.py ./out
```

預期：每個 DST 與 EXP 都能被 pyembroidery 讀回；針數、座標範圍、換色數與核心一致。`./out` 已列入忽略清單。

## 三、前端

```bash
cd web
npm install
npm run build:wasm      # 以 wasm-pack 編譯核心
npm run test            # vitest
npm run test:e2e        # Playwright（手機視窗）
npm run dev             # 本機開發伺服器
```

預期端到端流程（Playwright 會自動跑）：

1. 輸入「王小明」，預覽出現。
2. 選擇小框，輸入過長文字 → 看到白話說明且被縮小或阻止。
3. 新增 10×10cm 的框，之後重新整理仍在。
4. 按「存到 USB」，首次得到全部格式的檔案並顯示說明。
5. 斷網後重新整理，上述流程仍可進行。

## 四、離線與安裝

在 Android Chrome 開啟網址 → 選單「加到主畫面」→ 關閉網路 → 從主畫面開啟，確認可用。

## 五、給媽媽的實機測試清單（最後一步）

先把工具放到她的手機上（Android Chrome 開啟網址 → 選單「加到主畫面」）。請她在 B70 旁邊依序做：

1. 打開「刺繡小幫手」，輸入一個簡單的字（例如她的名字），選**小框**（原廠框 5×8 公分），按 **「全部都存，我要試試看」**。
   手機若問是否允許下載多個檔案，請按「允許」。你會得到同一個設計的兩個檔案，例如 `AMY0001.DST` 與 `AMY0001.EXP`。
2. 用「檔案」App 把這兩個檔案放進 USB 隨身碟（手機需要 OTG 轉接頭，或用有手機接頭的隨身碟），再插到 B70。
   *若「檔案」App 看不到隨身碟、或存不進去，請記下卡在哪一步，這是我們還不確定的部分。*
3. 看 B70 的畫面：**哪些檔案打得開？** 兩個都可以、只有一個可以、或都打不開，都請記錄。
   也請記下機器畫面上顯示的檔名是否正常（有沒有被截短、變亂碼）。
4. 打得開的，裝上小框，**先用機器的「描繪範圍」功能走一圈**，確認針不會打到框，再實際繡一次。
   觀察：大小與位置對不對、字有沒有糊、有沒有斷線或亂跳。
5. 回到工具，按下方的 **「機器打不開檔案？看這裡」**，在「哪一種機器打得開？」選能用的那一種，
   按 **「這個機器讀得到，以後就用它」**。之後「存到 USB」就只會存那一種。
6. 量一下**非原廠框**（例如 10×10 公分）裡面可以繡的範圍（不是木框外圈），按「＋ 新增我的框」填進去。
   再用同樣方式試繡一次，確認不會超出。
7. 拍照或回報：機器上檔案清單的畫面、讀得到的格式、繡出的成品、卡住的地方。

回報結果後：

- 把結論更新到 `knowledge/draft/2026-10-17-B70-檔案格式.md`，並固化進 `knowledge/vision.md`（階段 1 的成功標準）。
- 若兩種格式都讀不到，需要新增 B70 專屬格式（見 README 的「新增一種輸出格式」），其他程式不用改。
- 依成品調整「最小字高」「筆畫寬」「安全邊距」等數值（`crates/stitch-gen/src/design.rs` 的 `Settings` 預設值）。
