# Feature Specification: 手機刺繡工具（文字與簡單圖片）

**Feature Branch**: `001-embroidery-text-tool`（尚未使用 git，僅作為規格編號）

**Created**: 2026-10-17

**Status**: Draft

**Input**: User description: "為媽媽做一個手機網頁刺繡工具（Android Chrome、PWA、可離線）。輸入文字（繁體中文、英文、數字）或簡單圖片，預覽接近真實的刺繡效果，選擇繡框（含非原廠框），設計超出範圍時自動處理，輸出刺繡檔存到 USB 給 bernette B70 使用。因尚未能在 B70 實機確認支援格式，輸出格式必須可配置、可並存，一次可產生多種格式，讓媽媽之後逐一實測並記住預設格式。介面不得暴露技術術語。"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 輸入文字並產生刺繡檔 (Priority: P1)

媽媽打開手機上的工具，輸入一段文字（例如孫子的名字、日期或祝福語），選擇字型、大小和線色，看到接近真實刺繡的預覽，選好要用的繡框，按下「存到 USB」，得到可以插進 bernette B70 的檔案。

**Why this priority**: 這是整個產品存在的理由，也是她最常做的事（文字與圖片中的文字部分）。只做這一條就已經是可用的產品。

**Independent Test**: 在手機上輸入「王小明 2026」，選中框與一種字型和顏色，確認預覽出現且尺寸正確，產生的檔案能被一個獨立的檔案讀取程式讀回，且內容與預覽一致。

**Acceptance Scenarios**:

1. **Given** 媽媽開啟工具，**When** 她輸入繁體中文、英文或數字，**Then** 預覽立刻顯示對應的刺繡效果，字形完整、筆畫清楚。
2. **Given** 預覽已顯示，**When** 她調整字型、大小或線色，**Then** 預覽即時更新，不需要按「確定」。
3. **Given** 設計已完成並選好繡框，**When** 她按「存到 USB」，**Then** 她得到一組檔案，檔名簡短易懂，可直接放進隨身碟使用。
4. **Given** 她輸入的字太小，細節繡不出來，**When** 預覽產生時，**Then** 工具自動放大到可繡的最小尺寸，或用白話告訴她「這個字太小，繡出來會糊，已幫你放大」。

---

### User Story 2 - 選擇繡框並避免超出範圍 (Priority: P1)

媽媽有 bernette B70 的原廠繡框，也有非原廠的框（例如 10×10cm）。她要能選擇現在裝在機器上的框，工具要確保設計不會超出那個框可以繡的範圍。

**Why this priority**: 設計超出繡框會讓針打到框，可能斷針或損壞機器，是唯一會造成實際傷害的錯誤，必須在輸出前擋下。

**Independent Test**: 選擇 50×75mm 的小框，輸入很長的文字，確認工具自動縮小或阻止輸出，並顯示白話說明；改選大框後，同一段文字可以正常輸出。

**Acceptance Scenarios**:

1. **Given** 工具內建 B70 原廠三種框（大 160×260mm、中 120×180mm、小 50×75mm），**When** 她開啟選框畫面，**Then** 這三種框可直接選用。
2. **Given** 她有一個非原廠框，**When** 她新增框，輸入名稱、可繡的寬與高，並選形狀（方形、圓形或橢圓），**Then** 新框出現在清單中，之後重開工具仍然存在。
3. **Given** 設計超出所選框的可繡範圍，**When** 她按「存到 USB」，**Then** 工具自動縮小設計使其放得進去；若縮小後細節會繡不出來，則阻止輸出並用白話說明原因與建議。
4. **Given** 她新增框時只輸入外框尺寸，**When** 工具要判斷可繡範圍，**Then** 工具預留安全邊距，並在新增畫面用圖示提示「請量內框可繡的範圍」。
5. **Given** 她編輯或刪除自己新增的框，**When** 儲存，**Then** 內建的原廠框不受影響且不能被刪除。

---

### User Story 3 - 輸出多種檔案格式供實機測試 (Priority: P1)

目前尚未確認 B70 能讀哪種檔案格式。工具要能一次輸出多種格式，讓媽媽拿到機器前把全部放進隨身碟，逐一測試，找出機器讀得到的，然後告訴工具「以後就用這個」。

**Why this priority**: 這是整個產品能否在實機上用的關鍵不確定因素。沒有這條，即使前面都做對，也可能繡不出來。

**Independent Test**: 選擇「全部格式都存」，確認得到每種格式一個檔案，檔名可分辨且同一設計成對應；在設定中選定預設格式後，之後預設只輸出該格式。

**Acceptance Scenarios**:

1. **Given** 設計已完成，**When** 她選擇「全部都存，我要試試看」，**Then** 她得到每一種支援格式各一個檔案，檔名包含設計名稱與格式標示，容易分辨。
2. **Given** 她已測試出機器能讀哪一種，**When** 她在設定中選定預設格式，**Then** 之後「存到 USB」預設只輸出該格式，重開工具後仍然記得。
3. **Given** 她尚未選定預設格式，**When** 她第一次按「存到 USB」，**Then** 工具預設輸出所有支援的格式，並用白話說明「這是第一次，我先全部都存，請試試哪一個機器讀得到」。
4. **Given** 日後要支援新的檔案格式，**When** 新增格式，**Then** 既有的設計與設定不受影響，新格式自動出現在選項中。
5. **Given** 工具提供測試說明，**When** 她需要測試，**Then** 她看到簡短的步驟說明（放進隨身碟、插到機器、看能不能打開）以及「能讀到的就選這個」的按鈕。

### User Story 4 - 簡單圖片轉成刺繡 (Priority: P2)

媽媽選一張手邊的簡單圖案（色塊明確的插畫或標誌），工具把它轉成刺繡預覽，她可以調整顏色數量與簡化程度，然後同樣存到 USB。

**Why this priority**: 圖片是她第二常用的輸入，但轉換品質難度高；先確保文字流程完整可用，再加入圖片。

**Independent Test**: 選一張 3 色的簡單圖案，確認預覽顯示對應的 3 種線色，且過小的細節被自動簡化；輸出的檔案能被獨立程式讀回。

**Acceptance Scenarios**:

1. **Given** 她選了一張圖片（相簿或拍照），**When** 轉換完成，**Then** 她看到刺繡預覽，顏色已限制在可用線色的合理數量內。
2. **Given** 預覽已顯示，**When** 她調整「顏色多寡」或「簡化程度」，**Then** 預覽在數秒內更新。
3. **Given** 圖片細節太細繡不出來，**When** 轉換時，**Then** 工具自動簡化，並用白話告知「有些地方太細，已幫你合併」。
4. **Given** 她選的是顏色漸層複雜的照片，**When** 轉換時，**Then** 工具告知這類圖效果有限，建議改用色塊明確的圖，仍允許她繼續。

---

### User Story 5 - 離線與重開後保留設定 (Priority: P2)

媽媽可能在沒有網路的地方使用。工具要能離線運作，並記住她的繡框、預設格式、最近的設計。

**Why this priority**: 手機在家用時網路穩定，但可靠性影響信任感；記住設定則降低每次操作的負擔。

**Independent Test**: 第一次開啟後關閉網路，重新開啟，確認輸入文字、預覽、選框、輸出皆可運作，且之前新增的框與預設格式仍在。

**Acceptance Scenarios**:

1. **Given** 她至少成功開啟過一次，**When** 之後沒有網路，**Then** 文字刺繡、選框、輸出都能運作。
2. **Given** 她關閉瀏覽器再開，**When** 重新進入，**Then** 她自訂的框、預設格式與最近的設計仍然存在。
3. **Given** 她可以把工具加到手機主畫面，**When** 她從主畫面開啟，**Then** 體驗像一般應用程式，沒有網址列干擾。

---

### Edge Cases

- 文字過長：自動換行或縮小；仍放不下時阻止輸出並建議換大框。
- 筆畫繁多的中文字（例如「龍」「鑿」）在小尺寸：偵測最小可繡字高，自動放大或提示。
- 輸入空白或只有空白字元：不產生檔案，提示「請先輸入文字」。
- 輸入的字型不含某個字：自動以其他字型補上並提示，或提示換字型。
- 非原廠框尺寸輸入不合理（零、負數、遠大於機器上限）：白話提示並要求更正。
- 設計正好貼著框邊：以安全邊距為準，不允許貼邊。
- 存到 USB 失敗（隨身碟未插、空間不足、檔案名稱不被接受）：說明原因與下一步，不丟失設計。
- 圖片過大或格式不支援：自動縮小處理，或告知不支援的格式。
- 低階手機運算較慢：顯示進度，介面不凍結。
- 圖片只有單一顏色或完全空白：給出合理結果或友善提示。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系統 MUST 讓使用者輸入繁體中文、英文與數字文字，並在輸入時即時更新刺繡預覽。
- **FR-002**: 系統 MUST 提供多種字型選擇，所有字型的授權 MUST 允許在本工具中使用與散布。
- **FR-003**: 使用者 MUST 能調整文字大小與線色，預覽即時反映。
- **FR-004**: 預覽 MUST 呈現接近真實刺繡的外觀（線的紋理與方向），而非單純線稿。
- **FR-005**: 系統 MUST 偵測過小而繡不出的細節（字高、筆畫寬度低於可繡下限），並自動調整或以白話提示。
- **FR-006**: 系統 MUST 內建 bernette B70 原廠三種繡框（大 160×260mm、中 120×180mm、小 50×75mm）。
- **FR-007**: 使用者 MUST 能新增、編輯、刪除自己的繡框，每個框含名稱、可繡寬與高、形狀（方形、圓形、橢圓）；內建框 MUST NOT 可被刪除。
- **FR-008**: 系統 MUST 在可繡範圍外預留安全邊距，並確保輸出的設計完全落在安全範圍內。
- **FR-009**: 設計超出可繡範圍時，系統 MUST 自動縮放；縮放後仍不可行時 MUST 阻止輸出，並以白話說明原因與建議。
- **FR-010**: 系統 MUST 能將設計輸出為刺繡檔，供 USB 隨身碟傳輸到機器。
- **FR-011**: 系統 MUST 支援至少兩種刺繡檔格式（DST 與 EXP），並 MUST 以可擴充的方式設計，使新增格式不影響既有設計與設定。
- **FR-012**: 系統 MUST 支援一次輸出所有支援的格式；每個檔名 MUST 包含設計名稱與格式標示，簡短、不含機器可能不接受的字元。
- **FR-013**: 使用者 MUST 能選定預設輸出格式，系統 MUST 記住該選擇；未選定前，預設 MUST 輸出所有格式並說明原因。
- **FR-014**: 系統 MUST 提供簡短的實機測試說明，並讓使用者在測試後一鍵設定預設格式。
- **FR-015**: 系統 MUST 允許使用者選擇圖片（相簿或拍照），並將色塊明確的圖片轉為刺繡預覽。
- **FR-016**: 圖片轉換 MUST 讓使用者調整顏色多寡與簡化程度，並限制顏色在合理數量內。
- **FR-017**: 系統 MUST 在使用者介面中使用刺繡與拼布的慣用語與繁體中文，MUST NOT 暴露檔案格式縮寫以外的技術術語（例如 quantization、解析度參數）；格式名稱僅在測試說明與設定中以易懂方式出現。
- **FR-018**: 所有錯誤訊息 MUST 以白話說明原因與下一步；能自動修正的 MUST 自動修正。
- **FR-019**: 所有編輯動作 MUST 可復原。
- **FR-020**: 系統 MUST 能在曾成功載入一次後離線運作，且 MUST 能加到手機主畫面以類似應用程式的方式開啟。
- **FR-021**: 系統 MUST 在本機保存使用者的繡框、預設格式與最近設計，重開後仍存在。
- **FR-022**: 使用者的文字、圖片與設計 MUST 預設只在其裝置上處理，MUST NOT 未經同意上傳到任何伺服器。
- **FR-023**: 輸出的檔案內容 MUST 可被獨立的檔案讀取程式正確讀回，且針跡座標與數量與預覽一致。
- **FR-024**: 長時間運算（例如圖片轉換）MUST 顯示進度，且介面 MUST NOT 凍結。

### Key Entities

- **設計（Design）**: 使用者正在製作的刺繡內容，由一或多個元素組成（文字或圖片），含位置、大小、線色與縮放。
- **文字元素**: 一段文字，含字型、大小、線色、排列方式。
- **圖片元素**: 由圖片轉換而來的色塊集合，含顏色數量與簡化程度。
- **繡框（Hoop）**: 名稱、可繡寬與高、形狀、是否為內建、安全邊距。
- **輸出格式（Output Format）**: 格式名稱、副檔名、對使用者的易懂說明、是否為預設。
- **使用者設定（Preferences）**: 預設輸出格式、最近使用的繡框、最近的設計。
- **針跡計畫（Stitch Plan）**: 最終要送給機器的針跡序列，含座標、類型（一般針、跳針、換色、剪線、結束）與顏色順序。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 媽媽在不看說明、不請人協助的情況下，能在 5 分鐘內完成「輸入文字 → 選框 → 存到 USB」。
- **SC-002**: 輸入文字後預覽更新在 1 秒內完成（一般長度，約 20 字以內，中階 Android 手機）。
- **SC-003**: 所有輸出檔案皆能被獨立的檔案讀取程式讀回，且針數與座標與預覽一致，成功率 100%。
- **SC-004**: 超出可繡範圍的設計，輸出前被擋下或自動縮放的比例 100%（不得有任何超出範圍的檔案被輸出）。
- **SC-005**: 在關閉網路後，文字刺繡完整流程（輸入、預覽、選框、輸出）全部可完成。
- **SC-006**: 至少一種輸出格式在 bernette B70 實機上被成功讀取並繡出（由媽媽實測確認）。
- **SC-007**: 簡單 3 至 5 色的圖案，圖片轉換在 10 秒內完成並顯示預覽（中階 Android 手機）。
- **SC-008**: 在可用性測試中，媽媽能自己找到「全部都存」並完成一次格式測試與設定預設格式，無需旁人指導。

## Assumptions

- 主要使用者是媽媽，使用 Android 手機（Chrome 瀏覽器），機器為 bernette B70。
- bernette B70 支援的檔案格式尚未確認，需要媽媽實機測試；在此之前輸出多種格式並存。SC-006 要等實測後才能驗收。
- 預設內建 B70 原廠三種框的尺寸取自零售商公開資訊（大 160×260mm、中 120×180mm、小 50×75mm），實際可繡範圍以機器為準，使用者可編輯。
- 非原廠框機器可能無法自動辨識，因此安全範圍由本工具負責把關；預設安全邊距為 5mm，可調整。
- 範圍僅限文字與簡單圖片；不包含照片的高品質自動轉換、專業節點編輯、圖層、多機型專屬格式的深度支援。
- 手機透過 USB 隨身碟（OTG）或檔案管理員將檔案存入隨身碟，具體傳輸方式不在本功能內控制，但提供簡短的操作說明。
- 字型採用授權允許嵌入與散布的開源字型，具體選擇留待計畫階段。
- 技術選型（核心語言、執行環境、前端框架）留待計畫階段決定；使用者已表示核心偏好以 Rust 實作並編成可在瀏覽器執行的形式。
- 開發 MUST 遵循專案憲章：測試先行（TDD）、規格與文件使用繁體中文。
- 檔案儲存與設定僅在使用者本機，不需要帳號或登入。
